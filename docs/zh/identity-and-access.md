# 身份与权限

Hub 默认私有、无公开注册，企业首次登录默认等待审批。匿名浏览需部署方明确开启。客户端不是统一账号中心，不合并跨 Hub 用户或同步权限。

## 身份、主页与授权分离 [#separate-identity-profile-and-authorization]

| 层次 | 边界 |
| --- | --- |
| 登录身份 | 本地密码或可配置的 OIDC/GitHub 适配器，第三方身份绑定验证后的身份域/subject，不按邮箱匹配 |
| Hub 成员资格 | 每个 Hub 独立管理用户 ID、账号状态、会话，同名不表示同一主体 |
| 社区主页 | 展示名、简介、头像按可读贡献/共同团队公开；登录用户名仅本人及有权管理人员可见 |
| 访问分组 | 授予内容受众和命名空间角色，不是公开团队，不从企业目录自动同步 |
| 团队 | 企业模式下，已登录成员可发现全部未归档团队的名称和简介。技能受众、操作权限独立校验；成员列表仅命名空间成员和 Hub 管理员可读。社区模式按可见技能或命名空间成员身份发现团队。 |
| 内容受众 | 不可变版本的 Public、Members、Groups，与登录方式独立 |

主页仅向本人、Hub 管理员，或有可读发布贡献、未删除评论、共同命名空间关系的人开放。登录不代表可按 ID 枚举全部用户；未知和不可访问用户均返回不存在。公开作者使用 Hub 内不透明 ID，展示名不回退到他人的登录用户名。

没有分别编辑的“企业/公开账号”或双主页。发布公开内容可能连带公开作者社区主页；内部部署应保持私有。改公开前应盘点内容和主页暴露范围。

## 有效权限 [#effective-permissions]

| 身份 | 内容与操作 |
| --- | --- |
| 匿名 | 仅公开 Hub 中已发布的 Public 版本，无写入/管理 |
| 普通成员 | Public、Members 及其他已获授权内容；编辑自身资料/本地密码，不默认拥有发布审核能力 |
| Reader | Public、Members；Groups 仍需受众分组成员资格 |
| Maintainer | 命名空间内容和提交；发布、撤下；审核需另有 Reviewer/Admin |
| Reviewer | 命名空间内容和提交；独立审核，不能自审；发布需另有 Maintainer/Admin |
| Namespace Admin | 命名空间发布、审核、角色、团队主页和策略，不是 Hub 用户管理员 |
| 人员管理员 | 创建普通账号、审批准入、启停普通账号；无额外内容权限、密码重置或角色授予能力 |
| 审计员 | 只读审计；无额外内容访问或变更权限 |
| Hub 管理员 | 全 Hub 内容、用户、分组、授权、分类与审计；仍不能自审或绕过扫描阻断 |

授权叠加，无显式 deny。Reader 不绕过 Groups 受众，移除分组成员资格立即影响后续读取。Maintainer、Reviewer、Namespace Admin 可为履职读取本命名空间 Groups 内容；Hub 管理员可读取全部内容。因此不能把该存储当作对这些可信角色保密的系统。

**Members 是全部有效 Hub 成员，不是某个团队成员。** Public 在私有 Hub 中仍需登录；切换公开可能使历史 Public 版本匿名可见。发布默认受众为 Members。隐藏菜单不是权限边界，服务端始终校验。

目录、详情、评论、下载、缓存复用在撤权/撤下后重新校验，已复制到设备的文件无法远程收回。收藏仅本人可见。审核绑定内容与受众，修改内容或扩大受众需重新发布。

## 企业准入 [#enterprise-admission]

使用身份提供方的应用分配控制可登录人群，保留本地应急管理员。默认首次验证进入审批；准入审批不授予发布、审核或平台职责。可显式启用自动准入。

不自动转换本地账号，不支持邀请认领、身份预绑定、SCIM、目录分组映射、即时离职同步或账号迁移。企业会话八小时；即时离职需禁用 Hub 账号，不能只禁用身份提供方。参见[企业登录](enterprise-login.md)。

## 验证授权 [#verify-authorization]

用非管理员账号验证角色组合、分组撤权、独立审核及不可访问资源隔离。管理员演示不是权限测试。参见[测试](testing.md)和[部署检查](deployment-checklist.md)。

[社区模式](community-hosting.md)调整准入与投稿默认策略，不引入第二套用户或角色体系。

## 本机客户端会话

App 和 CLI 通过密码或浏览器设备授权登录时申请可续期的 Hub 会话。访问令牌、刷新令牌、到期时间与待重试的刷新请求标识一起保存在系统凭据库，不进入本地元数据数据库、前端绑定或日志。各个连接分别保存会话。

访问令牌有效期为 15 分钟。刷新会话在 30 天未续期后失效，单次登录最长持续 90 天。访问令牌剩余不足一分钟时，请求会先刷新；App 启动及唤醒时重新检查身份。CLI 和 App 使用跨进程连接锁避免重复刷新；刷新前持久化请求标识，响应丢失后可恢复同一次轮换。旧访问令牌最多保留一分钟供在途请求完成；以不同请求标识重用上一枚刷新令牌会撤销该会话。

断网保留凭据以供重试。撤销、修改密码、停用账号或刷新会话到期后需要重新登录。每次请求仍检查当前权限。Hub 不保存微软或 GitHub 的第三方令牌；身份提供者停用账号不会自动同步到 Hub，管理员需在 Hub 停用对应账号。

已有不可续期凭据维持原有效期；对升级后的 Hub 重新登录一次即可获得可续期会话。环境变量提供的自动化令牌按自身有效期工作，不自动续期。浏览器 Cookie 会话维持原有效期。
