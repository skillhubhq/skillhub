# 产品边界

本地配置通过可选声明描述每个安装的要求，CLI 与 App 共用本机非敏感配置、系统凭据库和环境变量引用。诊断不返回配置值，版本变化后需确认当前摘要，匹配的已有配置值会继续使用；所有值均不上传 Hub。用户可主动将所选安装的配置通过本地管道加载到 Bash、Zsh 或 PowerShell，检查当前进程并清理新增变量；SkillHub 不向现有进程注入，也不启动 Agent。参见[本地配置与密钥](local-configuration.md)。

SkillHub 是自建的技能仓库，用于分享、审核和安装，面向拥有独立身份/权限的企业社区。它管理技能文件，不执行技能、不调用模型、不提供 Agent runtime。

## Hub、Web、App 与 CLI [#hub-web-app-and-cli]

| 组件 | 职责 |
| --- | --- |
| Hub | 身份、命名空间、分组、分类、不可变包、审核、社区和审计 |
| Web | 使用当前站点的 Hub，按权限浏览、贡献和管理 |
| App | 多独立 Hub 连接、社区浏览、本地编写与安装管理 |
| CLI | 通过共享 Go 内核脚本化相同远端/本地流程 |

默认私有且无公开注册，本地账号由管理员创建；企业登录默认审批。匿名读取需明确开启，写入/管理仍需认证。[身份权限](identity-and-access.md)与[企业登录](enterprise-login.md)说明边界。

## 发布与治理 [#publication-and-governance]

技能持有稳定名称、展示资料和访问规则，所有版本与社区互动共用其当前访问规则。已发布包不可修改，内容变化需新版本；待审核和被拒绝的提交可沿用拟发布版本号，每次修订生成独立提交并重新审核。命名空间可要求独立审核或直接发布，扫描风险可强制审核，作者不能自审。

命名空间组织归属，分组授予受众/角色，分类标签只辅助发现，团队是命名空间主页，不是第二套权限。评测是外部报告的版本证据，不执行、不认证，也不自动批准。

## 发现与社区 [#discovery-and-community]

目录先选每技能最高可读稳定语义版本；没有稳定版本时选择最高预发布版本，再按名称/展示名/描述、分类、标签筛选，可按名称、最近发布、精选浏览。最近指发布事件次序，不是最高语义版本；精选绑定稳定坐标，不改变可见性。点赞、评论、收藏不参与排名，无个性化推荐。

个人主页有展示名、简介和可上传头像，依据可读贡献发现，不泄漏私有贡献或登录用户名。PNG/JPEG 头像限制尺寸，裁剪重编码为 128px PNG 并移除元数据，不抓取任意外部图片。

点赞、私有收藏和讨论归属技能，发布新版本后继续保留。评论标注讨论的版本，单层回复跟随原线程。技能访问规则变化同时作用于历史版本和讨论；公开技能也会公开这些历史内容。收藏不可访问的技能时显示不可用状态，用户仍可移除。通知图标显示未读动态，审核待办单独计数；动态包含审核结果和评论回复，支持全部已读。

## 技能展示 [#skill-presentation]

`SKILL.md` 的 name 是稳定标识，版本可添加中英文展示名（各 80 Unicode 字符）和内置图标。显示回退顺序为当前语言→另一种已填写语言→稳定标识，不机器翻译作者内容。

维护者可独立编辑技能展示资料，操作校验并发修订并记入审计。版本包保留提交时的资料快照，本地安装使用快照离线显示。发布、卡片、详情、审核和本地清单遵循同一规则，不支持上传自定义技能图标。

## 导航与偏好 [#navigation-and-preferences]

App 分社区、本地技能、创作。创作及其发布、审核、管理入口按当前账号的实际 Hub 权限显示。会话失效时同步清除账号相关导航和私有内容；返回窗口时重新验证会话。选中 Hub 决定社区身份/发布审核管理，本地清单/项目跨来源，无全局 Hub 选择器。每个操作保留明确来源。

App 默认搜索当前 Hub，可显式跨所有连接，结果、权限和错误仍独立。Web 只搜索当前站点，名称放 Logo 旁，不显示多 Hub 切换。界面默认英文，支持简体中文和系统/浅/深主题；偏好属于设备，社区分类/内容属于作者数据。文档提供对应中英文目录和本地搜索。

## 本地安装与编写 [#local-installation-and-authoring]

App/CLI 共用连接、凭据引用、安装清单、项目入口和内核；每源有别名、URL、实例 ID 和独立凭据。技能更新用保存来源，身份缺失/歧义时需显式恢复。

Codex/Claude Code 支持项目/全局目录，项目内工具别名不能逃出项目。安装校验权限和摘要、预览计划、锁定、暂存、原子替换和事务恢复，不静默覆盖本地修改或未受管内容。撤下只阻止未来下载，不删除已安装副本。

项目清单指定精确版本/工具，锁记录身份、URL、摘要、相对目标，不含凭据。统一变更预览解析锁定版本并显示安装和移除，确认后逐目标应用和报告；技能更新不自动改项目锁。缓存复用也需在线授权，网络失败不是“已撤下”或“已最新”。

App 支持本地草稿编辑和预览，保存的有效/不完整文件均可重开；发布表单与已保存文件按 Hub 和账号保存在设备，恢复时重新检查权限；浏览器草稿存入同源 IndexedDB。Web 提供归档发布和安装指引/下载，不能直接写本地工具目录。

## 部署与分发 [#deployment-and-distribution]

一个 Go Hub 内嵌 Web/静态文档，支持 SQLite/PostgreSQL 和本地不可变包，无额外守护进程、Redis、队列或搜索集群。不支持多节点、S3、SCIM、多阶段审核、外部扫描器或 Agent 执行。

GitHub 分发软件，App 显式检查并手动安装；不会顺便更新技能或 Hub。软件 Apache-2.0 与托管技能的独立许可/权限分开。见[分发](distribution.md)、[运维](operations.md)和[部署检查](deployment-checklist.md)。

## 社区部署模式 [#community-mode]

[社区模式](community-hosting.md)使用同一账号与权限体系，启用第三方身份自动准入、个人投稿空间、强制独立审核与配额。登录适配器独立于模式配置；GitHub 与 OIDC 均可用于企业或社区模式。默认仍为企业准入审批。

## 团队归档

归档停止写入并从默认发现页隐藏团队，已有权限仍可读取历史和下载包。撤下版本用于停止分发。清理包正文保留技能互动、版本标识和审计；永久清理团队需要明确确认其影响范围。

## 版本交付

订阅跟随技能，发布通知遵循当前访问权限。版本比较读取两个已授权的不可变包，返回有大小限制的文件差异。

技能套装是携带 `skillhub.suite.json` 的正常审核包，包含同一 Hub 的精确成员版本、摘要和入口技能。客户端展开安装计划，记录共享成员归属，Hub 逐项验证成员。

自动化令牌绑定所有者，仅保存哈希，具备有效期和撤销能力。只读令牌访问目录；投稿令牌额外允许向指定团队提交。令牌不能审核、管理或创建凭据，始终受当前账号权限约束。
