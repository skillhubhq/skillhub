# 官方社区

[skills.codectn.com](https://skills.codectn.com) 是 SkillHub 官方公共社区。自建 Hub 拥有独立账号、内容和权限；连接自建 Hub 不会把凭据或私有技能发送到官方服务。

## 连接与浏览 [#connect-and-browse]

App 的新配置没有任何连接时，会尝试匿名连接官方 Hub，发现请求最多等待三秒，离线后可重试。已有配置保留原连接。删除官方连接后会记住这一选择，不自动加回；可通过「设置 → 连接与账号 → 连接官方 Hub」重新添加。

「官方」标识匹配配置中的官方 HTTPS 地址，不取决于 Hub 自报名称，也不代表对技能作者的背书。第三方 Hub 改名不能获得标识。使用任何技能前都应检查其代码与指令，官方社区托管的技能也不例外。

## 在 Web 与 App 间打开 [#open-between-web-and-app]

技能页面的「安装技能 → 桌面 App → 在 SkillHub 中打开」定位精确的 Hub、技能与版本。App 展示来源，连接新 Hub 前要求确认；不会接收浏览器 Cookie 或 GitHub Token。工具、项目/全局位置和文件变更预览需另行选择与确认。

`skillhub://open` 仅接收 `hub`、`skill`、`version`，不能指定本地目录、运行 Agent、授予权限或自动安装。macOS 由安装后的应用包注册协议；Windows 在首次启动 App 时为当前用户注册，无需管理员权限。浏览器无法打开 App 时，可下载 App，或复制 Hub 地址和技能坐标；ZIP 下载与 CLI 安装指引仍保留。

App 详情中的「在来源网站查看」打开托管 Hub 上的同一技能版本。私有 Hub 可能要求另行登录浏览器，链接不会携带凭据。

## 第三方技能精选 [#curated-third-party-skills]

官方托管不等于官方原创。收录前记录上游仓库、精确提交、目录和许可证，保留必要的许可证、NOTICE 和作者归属。仅打包所需技能及引用文件，校验归档并人工检查静态扫描发现，不运行随包脚本。

使用独立精选命名空间，明确说明是上游内容副本，不冒充原创或上游背书。固定导入版本，更新经审核后发布新版本，并提供移除和联系渠道。热门程度不能证明安全或再分发权；仅源码可见或许可证不明确的内容需另行审核。
