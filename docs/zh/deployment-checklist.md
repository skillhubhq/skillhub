# 部署检查

用于准备私有单实例 Hub，具体地址、凭据、责任人和完成报告保存在源码外，验收确切候选 revision。这是环境集成清单，不是代码发布门禁；真实环境可待验证，但不能声称已通过。代码验收见[测试](testing.md)。

## 真实 Entra 与身份生命周期 [#real-entra-application-and-identity-lifecycle]

- [ ] 指定应用所有者/准入审批人，按组织流程建单租户应用。
- [ ] 填租户 issuer、Client ID、精确 HTTPS 回调，密钥受控注入，检查不进前端、客户端、日志、Git。
- [ ] 要求应用分配，明确员工/来宾/MFA，分别验证已分配与未分配普通用户。
- [ ] 完成首次验证→待审批→普通成员→重登，确认不附带发布/审核/平台权限。
- [ ] 通过真实代理测试 Web 和设备授权、过期/取消/错误回调/重放，不记录令牌。
- [ ] Hub 禁用立即撤销会话；Entra-only 禁用不即时同步，明确离职同时禁用的责任人。如果必须自动即时同步，当前无目录同步需另行解决。
- [ ] 保留受控本地应急管理员，IdP 不可用时验证，约定保管/轮换，不按邮箱合并账号。

## 服务器、隔离与恢复 [#target-server-isolation-and-recovery]

- [ ] 专用 PostgreSQL 与加密持久卷，支持主版本和匹配工具，不共用其他服务 schema。
- [ ] 最小服务权限、密钥文件权限、HTTPS、数据库 TLS 或审查后的同机隔离、精确代理信任。
- [ ] 重启后 origin/实例 ID/包持久性不变，先停旧再起新，不并行滚动服务。
- [ ] 配置进程恢复与认证目录/下载探测，真实代理后不同用户限流独立。
- [ ] 磁盘、备份、服务故障有告警责任人，用隔离目标验证磁盘满/数据库不可用。
- [ ] 定义 RPO/RTO、周期、保留和独立加密副本；PostgreSQL 配套备份需停机，测量维护窗口。
- [ ] 恢复到新数据库/目录，检查身份、包摘要、角色、扫描、通知、精选、评测；旧会话拒绝，新登录成功。
- [ ] 用确切旧程序/配置演练升级回退，重新开放前核对快照后的禁用、角色、密码变化；回退不是反向迁移。

## 产品与候选验收 [#product-and-candidate-acceptance]

- [ ] 使用合成内容建两个命名空间/独立分组，验证匿名、普通成员、受限 Reader、维护者、审核者、人员管理员、审计员、Hub 管理员。
- [ ] 搜索/最近/精选/详情/评论/评测/下载/待办总数守权限，撤权/撤下消失，本人提交不能自审。
- [ ] 完成提交→要求修改→新版本→独立批准→通知→精确安装→更新→撤下提示，错误中保留本地文件。
- [ ] 外部评测导入精确版本，受众正确、无私有数据，撤回后不能继续读取正文；静态扫描与评测明确区分。
- [ ] 测实际包尺寸、页面行为、并发延迟，对照组织容量需求。
- [ ] 固定候选 revision，跑全 CI/平台矩阵，记录摘要/来源/支持版本。
- [ ] 干净 macOS 以浏览器下载 DMG、正常安全策略安装替换，保留连接/凭据/草稿/偏好/技能；不把测试 bundle 的结果当真实发行身份/quarantine 验收。
- [ ] 重启后从保存凭据访问两个源、重开有效/不完整草稿、比较全局/项目及本地修改，确认 IT 接受手动安装方案。
- [ ] 若包含 Windows，验收真实 WebView2、凭据存储、安装/更新；否则明确本次范围。

## 运维责任 [#operating-responsibilities]

邀请用户前明确支持、备份、审批、独立审核责任人和维护窗口/升级渠道。先小范围试用并记录完整闭环。邮件提醒、SCIM、自定义角色构建、公共社区治理及自动 App 安装不默认包含。
